# ООО «Примаслоторг» - сайт-каталог

Первая версия многостраничного корпоративного сайта-каталога для продажи масел и технических жидкостей для спецтехники.

## Стек

- Node.js
- Express.js
- EJS
- SQLite
- bcrypt
- express-session
- multer
- CSS без фреймворков

## Запуск

```bash
npm install
npm run seed
npm run dev
```

После запуска сайт будет доступен по адресу:

```text
http://localhost:3000
```

Админка:

```text
http://localhost:3000/admin
```

## Основные страницы

- `/` - главная
- `/catalog` - каталог
- `/catalog/:categorySlug` - категория каталога
- `/product/:slug` - карточка товара
- `/about` - о компании
- `/delivery` - доставка
- `/contacts` - контакты
- `/privacy` - политика конфиденциальности
- `/admin` - админка

## Контакты

Контактные данные вынесены в файл:

```text
config/site.js
```

Там указаны email и два телефона компании.

## Изображения товаров

Файлы загружаются через админку в:

```text
public/uploads
```

Разрешены форматы: `jpg`, `jpeg`, `png`, `webp`.

Если изображение не загружено, на сайте показывается CSS-заглушка.

## База данных

SQLite-файл создается после seed:

```text
data/database.sqlite
```

Seed-скрипт создает таблицы, категории, 10 товаров-заглушек, страницы и администратора.
